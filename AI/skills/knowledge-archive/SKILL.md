# 知识库归档

## 用途

将当前对话整理为简洁、可检索、易维护的知识库更新。本技能不绑定具体工具，使用当前 agent 提供的文件发现、搜索、读取、写入和校验能力。

## 触发边界

- 仅在收到明确的归档请求后执行，例如 `#归档`、`归档知识库`、`同步知识库` 或含义明确的等价表达。
- 用户明确调用本技能也视为归档请求；普通的知识库分析、讨论或评审不视为归档请求。
- 不要自动归档普通讨论、推测性想法或尚未完成的分析。
- 如果对话没有形成已确认且可复用的结论，说明无需归档，不创建空文件。

## 归档流程

1. 从当前工作区、agent 上下文、已配置的项目路径或用户明确提供的路径中确定知识库根目录。不得假设厂商特定的绝对路径。
2. 检查根目录说明、项目入口文档、局部规则文件、命名约定和与当前对话相关的既有文档。根目录可以没有 `MOC`，此时使用现有的说明和规则文件。
3. 只提取已确认的事实，并分别整理背景、决策、约束、实施状态、影响和待定事项。证据不完整或互相冲突时，标注结论确定性。
4. 写入前先搜索。比较候选文档，选择主题一致且承担该主题唯一事实来源职责的既有文档。只有不存在合适归属时才创建新文档。
5. 按以下目标优先级归档：
   - 架构取舍、技术选型和长期边界 → 对应的 `ADR/` 目录；
   - 稳定的技术设计、数据模型、目录约定和工作流 → 对应的项目或全局设计文档；
   - 已完成的工作和有明确时间范围的进展 → 对应的日报；
   - 可复用的 AI 指令 → `AI/prompts/` 或 `AI/skills/`，但仅限对话明确将其确立为可复用内容；
   - 尚未解决的选择 → 待定事项或待决策章节，不得写成最终决策。
6. 保持唯一事实来源。完整结论只写入选定文档，其他位置只添加精确链接或简短状态引用。没有明确的跨项目复用证据时，不要把项目规则提升为全局 AI 规则。
7. 写入前准备简洁的归档预览，包含拟归档结论、确定性、目标文件和排除内容。目标明确且结论确定时可以直接继续；存在多个合理目标、可能形成长期规则或证据冲突时，先请求用户确认。
8. 保留历史。不得删除旧记录或为了体现当前状态而改写过去事件。如果旧决策被替代，保留原记录，并按知识库规则标记 `Superseded` 或 `Deprecated` 等关系。
9. 校验结果：检查最终差异或重新读取变更文件，确认章节、链接、目标路径、唯一事实来源位置和重复内容。遵循知识库既有链接语法，并确认被引用的文件确实存在。如果无法写入，提供明确标记的补丁或准确的建议修改，不得假装已经完成。
10. 汇总归档结果，说明重要结论、变更文件、待定事项和有必要说明的跳过内容。

## 内容规则

- 优先使用简洁中文和可检索的名词；只有为保证准确性时才保留代码标识符。
- 决策记录在信息具备时应包含背景、决策、理由、后果和状态。
- 不要把建议、实验或问题转换为正式决策。
- 保持唯一事实来源；已有长篇说明时，通过链接引用，不重复复制正文。
- 优先遵循仓库局部规则；规则冲突时，报告冲突并遵循更具体的规则。
- 仓库对 ADR 元数据、章节、编号、日报或链接有明确要求时，遵循仓库规则，不直接套用参考文件中的最小通用格式。
- 除非用户明确要求，不创建提交、不发布变更、不修改无关文件。
- 除非用户明确要求，不修改环境文件、生成文件或隐藏工具配置。

## 冲突与不确定性

- 当前代码、已接受的 ADR、设计文档和日报出现不一致时，记录为待定事项，并按照知识库规定的事实来源优先级处理；不得静默改写历史。
- 如果结论只是提案、实验或未来计划，将其放入待定事项或待决策章节，并明确标注状态。
- 如果对话涉及多个项目或互不相关的主题，将其拆分为独立的归档候选；没有已确认可复用内容的候选项直接跳过。

## 共享与运行时副本

- 仓库内的技能文件是可审阅、可追踪的共享来源。
- 如果宿主从安装目录加载技能，修改本文件后按宿主提供的安装或同步机制更新运行时副本，再依赖新的行为。
- 通用流程中不得写入用户目录、厂商特定的绝对路径或固定安装命令，应使用宿主提供的技能安装机制。

## 工具无关的执行契约

宿主 agent 可能以不同名称提供以下能力：

- **discover**：列出文件并识别知识库根目录；
- **search**：搜索相关文档和已有术语；
- **read**：读取规则和相关上下文；
- **write**：只创建或更新选定的文件；
- **validate**：检查最终差异或重新读取变更内容。

使用当前环境提供的等价能力即可，不要求特定的 shell、MCP 服务、编辑器、操作系统或 agent 厂商。如果宿主无法写入文件，返回明确标记的补丁或准确的建议修改。

## 输出格式

归档完成后报告：

- **重要结论**：提取出的内容及其确定性；
- **变更文件**：新增或更新的路径及其用途；
- **待定事项**：未解决的问题、缺失证据或规则冲突；
- **跳过内容**：有必要时说明对话中刻意未归档的重要内容。
