# 2026-08

## 月度概览

8 月围绕 ICCE 画布完成了从性能与几何基础、协作与变更架构到连线和 Table 交互的连续收敛。画布建立了大规模场景的性能观测、视口裁剪和按需渲染能力，计划提交链路与过程态协作边界进一步稳定；连线的业务几何、视觉几何、路由和控制点编辑逐步统一；月底开始形成 Table 的数据模型、单元格编辑、合并、行列操作和结构化复制粘贴能力。当前仍有部分视觉能力保持默认关闭或入口隐藏，后续需按实际需求决定是否开放。

## 主要工作

### 1. 优化画布性能并统一渲染、命中与几何基础

- 建立可复现的大规模节点场景和性能采样面板，引入图形与连线的增量空间索引、视口缓冲裁剪、文本按需挂载和缩放期间查询冻结，降低大画布渲染树规模及重复布局开销。
- 将普通文本、标签、条件内容、静态图片和富文本运行时纳入统一的画布渲染模型，使用显式节点元数据承载命中语义，并统一文字测量、字体回退和几何精度规则。
- 修复缩放平移后的命中错位、图形误选、编辑器文本漂移和富文本光标定位问题；视口订阅、画布命中和拖拽创建目标解析分别收敛到共享入口。

### 2. 收敛协作过程态、页面会话与变更提交边界

- 将选中结果与框选、绘制、移动、缩放、连线创建和重连等过程态分离承载，统一远端预览的开始、更新、提交和取消生命周期，并补齐离场清理、会话租约和页面切换期间的资源释放。
- 将画布持久化操作统一到计划、提交、变更集、发布链路，复合操作在投影快照上连续规划后一次提交；移动、缩放、区域扩容、推挤、后代位移、包含关系和连线变化由统一计划计算并以实际命令结果返回受影响范围。
- 收敛提交态失效语义为仅由业务内容变化触发，纯几何变化不再使已提交区域失效；命令结果只保留状态和影响范围，不为尚未立项的撤销重做、审计等能力预铺无消费者字段。
- 修复协作会话过早加入导致远端操作被忽略、审批后状态回读不一致、重复启动拖拽会话和预览残留等问题，并让提交和审批后的画布状态以服务端重载结果为准。

### 3. 统一连线几何、路由、视觉表现和编辑交互

- 将新建、吸附预览、端点重连、图形插入和最终落地统一到同一套端点归一化与路径生成入口；插入图形时先完成布局变化，再依据最新几何规划替代连线。
- 完善正交折线的候选路径、端点净空、避障、手动路径回退和控制点编辑；引入贝塞尔连线领域模型，支持内部锚点新增、调整和删除，并让普通折线同步支持内部折点删除。
- 将业务连线点与视觉渲染点分离，跳线弧和正交圆角只作用于渲染结果，不修改业务数据；连线渲染、命中、文本定位、端点控制和包围盒统一消费视觉几何服务。
- 让连线文本具备独立命中、选中、双击编辑和拖拽能力，补齐快捷添加预览的协作投影，并将绘制归属改为提交时按最终中心点解析。

### 4. 收敛画布交互工具、权限和界面状态

- 将指针点击候选、拖拽阈值、框选状态和正式交互会话分开，固定远端过程态、本地预览、高亮、选中框、连接点和控制点的覆盖顺序，减少误触、遮挡和无效会话。
- 统一上下文工具条与固定工具栏的描述项模型、权限过滤、弹窗定位、显示状态和命令分发；网格、跳线、全屏等画布显示状态与工具激活状态分离，区域草稿完整接入视觉、命中和交互会话。
- 将删除权限范围收窄为当前显式选中的区域和图形目标，并统一不同删除入口的判断结果；提交、审批、模板覆盖和插入图形继续遵循区域权限与应用命令边界。

### 5. 建立 Table 图形及单元格编辑能力

- 新增以稳定行列标识为基础的 Table 数据模型、稀疏单元格存储、合并关系和默认表格构造，完成创建工具、预览、网格渲染、单元格命中和单元格编辑接入。
- 支持表格等比缩放、行列尺寸同步、多行编辑、远端编辑预览、回车与 Tab 导航、方向键选区移动、删除键清空、范围框选以及表内结构化复制粘贴。
- 完善稀疏样式覆盖、合并区锚点归一、合并与拆分、行列插入删除、标题编辑和按单元格范围定位工具条；复制快照保留相对合并关系、行高和列宽，粘贴时按目标起点恢复并处理越界情况。

## 重点成果与影响

- 画布性能优化从单点渲染调整扩展为性能观测、空间索引、视口裁剪、文本挂载和共享几何的一体化链路，形成了可复现和可继续优化的基础。
- 画布变更的准入、领域规划、应用提交、协作预览和最终持久化边界更加明确，复合移动、缩放、区域副作用和远端回放能够沿统一链路处理。
- 连线创建、重连、插入、路由、渲染和控制点编辑共享稳定的几何语义，业务数据与视觉装饰分离，降低了不同交互入口产生不一致结果的风险。
- Table 已从图形基础设施推进到可编辑、可协作、可导航、可合并和可结构化复制粘贴的连续能力，稳定行列标识成为渲染、命中、编辑和重排的共同定位基础。

## 问题、风险与未完成事项

- 跳线弧已接入渲染链路但默认关闭，工具栏入口暂时隐藏；正交折线圆角算法保留但暂时隐藏，当前未作为默认交互开放。
- 8 月日报未记录撤销重做、审计或事务回放等历史能力已经立项或接入，当前仍按已有事实层和协作回放边界维护，不应提前扩展为完整历史能力。

## 架构与经验沉淀

- 画布交互应区分本地实时表现、远端过程预览和最终提交快照；一次用户操作的结束阶段才负责完整受影响范围和权威持久化。
- 几何能力遵循“领域快照与计划—应用事务执行—界面手势与预览”的边界，受影响目标以命令实际执行结果为准，区域扩容、推挤、后代传播和连线投影不得由界面层局部推断。
- 业务几何与视觉几何分开承载：业务点负责保存和编辑，视觉点负责圆角、跳线、采样、命中和文本定位；视觉优化不反向污染业务数据。
- 协作预览清理需要单一会话通道和明确终止消息，页面实例与共享协作运行时应通过独立租约管理生命周期，避免页面切换或异常退出造成状态残留。
- Table 的单元格、合并区和范围操作应使用稳定行列标识与锚点归一规则；编辑过程中的文本、行高和远端预览保持为过程态，提交时再写入正式数据。
