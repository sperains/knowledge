# 2026-09-08

## 今日概览

今天继续完善 ICCE Table 的实时协作体验：表格行列尺寸调整、行列重排、控制条悬停和单元格范围框选都接入远端过程预览，选中结果仍按独立快照同步；同时修复普通图形层级调整后画布节点顺序不更新的问题，并收敛表格单元格工具条中的层级入口。

## 今日工作

### 1. 表格协作过程预览与选中态同步

- 为行列尺寸调整、行列重排、控制条悬停和单元格范围框选补充协作过程消息、会话生命周期、远端状态和画布投影，远端可以跟随本地交互看到临时边界、落槽位置、控制点提示和单元格范围。
- 表格远端预览根据稳定的行列标识和当前表格几何计算视觉结果；行列尺寸调整期间使用临时表格数据投影主体，过程帧只更新远端预览状态，不写入正式图形数据。
- 单元格与范围选中结果继续放在 `selection` 快照中，范围拖拽过程中同步本地实时选区，结束或取消时分别提交或清理对应的 `interaction` 会话，保持选中结果与交互过程的生命周期分离。
- 表格控制条的悬停提示统一为浅色背景、边框和文字样式，并在进入、离开控制点时同步远端临时状态。

### 2. 画布层级同步与表格工具条入口收敛

- 为普通图形建立直接的 Konva Group 渲染根节点，并在 Vue 更新完成后按当前图形顺序同步画布节点层级，修复置顶、置底等层级调整只更新数据顺序而未更新实际画布顺序的问题。
- 将表格单元格的层级命令作用域归到所属的 Table Shape，移除单元格工具条中重复的层级菜单，避免把单元格当作独立画布对象调整层级。

## 架构与经验沉淀

- Table 内部的行列拖拽、尺寸调整、控制条悬停和范围框选都属于 `interaction` 过程态，必须携带会话标识并由独立远端预览状态承载；单元格与范围的最终选中结果属于 `selection` 快照，不能混入过程消息。
- 远端表格视觉需要把正式的 Table Shape 与过程态临时几何统一投影后再渲染，不能为了显示协作过程而改写正式图形数据。
- 画布层级调整需要有稳定的直接渲染根节点；模板生成的片段顺序变化不会自动保证 Konva 节点顺序同步，数据排序和画布节点排序应分别确认。
