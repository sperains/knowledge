## 2. 不变边界

### 2.1 一个 Table 仍是一个 Shape

- 画布只持久化一个 `type: 'table'` Shape；标题、行、列、单元格和合并关系均在 `data.table`。
- 行列和单元格不创建独立 Shape，也不建立 `CanvasRelation`。
- 行列 ID 决定稳定身份，数组顺序只表示显示顺序；外框宽高始终等于行高和列宽总和。

### 2.2 持久化与本地过程态分离

- `cells` 是稀疏记录：只有文本或单元格样式覆盖才保存。
- `merges` 独立记录合并锚点和有序行列 ID；覆盖格不保存冗余数据，运行时统一解析到锚点。
- 单元格或范围选中、hover、编辑草稿、HTML 编辑器焦点与拖拽预览均是本地过程态，不写入 Table 数据或历史记录。
- 每次完成编辑、样式、合并或拆分只通过一次完整 Table Shape 更新提交；过程预览不产生正式 Shape 修改。

## 3. TBL-001 至 TBL-006、TBL-022：创建、选择、编辑与缩放

### 3.1 创建与渲染

- 新建 Table 固定初始化为 3×3，默认列宽 200、默认行高 60，网格为 600×180。
- 主体网格、背景、边框、文字和只读标题由 Konva 渲染；选择框和单元格范围高亮在 SelectionLayer；活动编辑器挂载到 HTML Overlay。
- HTML Overlay 不继承 Konva 变换，因此编辑器只在进入时换算一次坐标；视口平移或缩放期间隐藏编辑器，结束后恢复，避免视觉漂移。

### 3.2 选择与键盘状态链

```text
Table 整体选中 → 点击单元格 → 单元格选中 → Enter → 编辑态
编辑态输入或切格 → 本地预览 / 协作过程消息 → 保存 → 一次 Shape 更新
```

- 单元格选中后按 Enter 进入编辑；Tab 无论是否编辑都移动到下一单元格，编辑态先保存，末格回到首格。
- Esc 按层退出：编辑态退出编辑，单元格选中态清除单元格选择；Delete 或 Backspace 只清空当前单元格，不删除 Table。
- 点击其他单元格会保存旧单元格并将编辑器焦点稳定转移到新单元格；点击 Table 外部保存并转交画布选择。

### 3.3 多行编辑与协作预览

- 编辑器为单一多行文本框，支持换行、中文输入法和按内容撑高目标行。
- 输入过程中发布 `table-cell-edit` 的本地与远端临时预览，包含文本与仅增长的目标行高；保存时一次正式提交，取消时发送重置并清除预览。
- Konva 只读文本与 HTML 编辑器统一使用 `Noto Sans, HarmonyOS Sans SC, sans-serif`，避免编辑态与显示态字体漂移。

### 3.4 四角缩放

- 仅显示四角控制点；缩放按统一比例更新所有列宽和行高，文字字号不变。
- 拖拽阶段使用临时几何预览，释放时将外框与 `data.table` 尺寸一次写入既有 Plan → Commit → ChangeSet → Publish 链路。

## 4. TBL-007 至 TBL-010：已完成的领域数据变换

### 4.1 批量粘贴

- 外部文本按换行和制表符解析为二维矩阵，空值同样是有效写入，会清空对应目标单元格。
- 外部文本粘贴超出边界时按默认尺寸追加行列；起点命中合并覆盖格时先解析到锚点，后续落入同一合并区的覆盖位置跳过写入，且不复制尺寸和合并关系。
- ICCE 内部复制保存连续范围的完整快照，包含单元格数据、范围内行高、列宽和相对合并关系。
- 内部粘贴按目标起点恢复源范围行高和列宽；超出边界新增的行列先创建，再应用快照尺寸。
- 内部粘贴前移除目标矩形内相交的旧合并关系，再按相对坐标重建源合并结构，确保新旧合并关系不重叠。

### 4.2 行列插入、删除与锚点迁移

- 插入行列继承相邻尺寸和样式；插入边界穿过合并区时，合并区扩展并清理新覆盖格。
- 删除行列会收缩受影响合并区；删除锚点时将内容和样式迁移到剩余区域的新左上角；收缩为 1×1 时删除合并关系。
- 删除最后一行或列返回由应用层删除整个 Table 的信号，领域函数不直接修改 Store。

### 4.3 行列控制条与上下文操作

- SelectionLayer 负责渲染网格上方和左侧的行列控制条、插入点和无标题 Table 左上方的 3×2 拖拽点阵；这些控件属于本地交互覆盖层，不写入 Table 数据。
- Table 本体、所属 Region 和控制条之间通过本地悬停状态完成交接；控制条舞台尺寸过小时统一隐藏控制条和左上角点阵，避免低缩放噪声。
- 点击行列控制条只建立对应整行或整列范围，用于高亮控制条和显示上下文删除入口；命中合并区域时不把整个合并区域变成单元格选区。
- 插入行列复用应用层结构变换命令，提交成功后清除单元格和行列选中状态；删除行列复用领域层收缩与锚点迁移，提交成功后选中删除位置左侧或上方的相邻行列，删除首行或首列时选中剩余首行或首列。
- 删除最后一行或列时，应用层将空结果转换为删除整个 Table Shape，并清除整体选中状态。

### 4.4 行列重排

- 行列重排的数据变换由 `domain/model/table.ts` 的纯函数承载；数组位置只表示当前显示顺序，源行列通过稳定 ID 定位。
- `getTableReorderGroup` 递归收集源行列参与的跨行或跨列合并关联组，组内顺序保持不变，关联组携带全部单元格数据整体移动。
- 重排坐标系先移除源关联组，`destinationIndex` 表示源组插入剩余行列序列的位置；首位和末位分别对应表格起始边界和末尾边界。
- 被拖拽行列组的中点越过目标块边界时更新落槽；目标边界进入其他合并关联组时以该组整体前后边界确定落槽，不允许拆开合并区域；进入源组自身时保持不变。
- `getTableReorderInsertionLineCoordinate` 根据同一个落槽计算最终高亮边界，线前的行列块是最终前项；释放后源组紧跟在高亮线前方行列之后，因此预览线与实际重排共用同一语义。
- SelectionLayer 在拖拽开始时选中当前行列，拖拽期间只维护本地影子和粗插入线，不改变底层表格顺序或操作条选中状态；释放后才通过一次完整 Table Shape 更新提交重排，取消则清除预览并保持原数据。

### 4.5 行列尺寸调整

- 行列边界作为 SelectionLayer 本地命中层渲染，不新增独立 Shape；行底边界使用纵向拖拽，列右边界使用横向拖拽，外框边界只承担对应目标行列的尺寸变化。
- 上边界只绑定首行，左边界只绑定首列；其余边界只绑定对应的相邻目标行或列。边界拖拽允许向内缩小或向外放大，候选尺寸只改变目标行高或列宽，其他单元格尺寸保持不变，Table 外框随网格总尺寸同步变化。
- 拖拽开始前先提交当前单元格编辑，避免编辑预览与尺寸会话交叠导致单元格塌缩；拖拽会话复用通用缩放过程态，只在几何预览中更新目标尺寸，退出键取消预览，释放后通过一次完整 Table Shape 更新提交。
- Table 图形缩放和行列尺寸拖拽期间隐藏控制条、边界命中与 hover 高亮，避免误触和高亮闪烁；控制条与边界按 Table 视觉宽高统一判断，任一边低于 100px 时不显示辅助控件。
- 双击边界按只读单元格的有效字体样式、显式换行和内容区宽度统一测量文本，并保留 8px 内边距；普通单元格直接适配，合并单元格以合并区总尺寸计算，超出部分只补到当前双击的目标行或列。
- 只读 Konva 文字、选中态覆盖层和编辑态文本框共用单元格内容区、有效样式和行高测量模型，编辑态仅切换承载层，不改变文本对齐规则。

## 5. TBL-013、TBL-014：合并、拆分与范围保持

### 5.1 合并感知范围

- 范围端点命中合并覆盖格时，先归一到锚点，再迭代扩展为完整连续矩形，保证视觉高亮、样式操作和结构操作面对同一范围。
- 范围地址在结构变换前被冻结为规范化矩形；命令成功后把该范围回写到本地选择状态。拆分恢复网格线后不会因锚点地址退回而缩小选区。

### 5.2 合并重组

```text
框选普通格 + 已合并区
        ↓
冻结完整选区 → 解除选区内合并关系（纯数据）
        ↓
以整个选区创建一个新合并区 → 一次 Table Shape 更新
```

- 已有合并区加周边格可直接点击合并，无需先拆分。
- 内容按行优先顺序汇总，以换行连接非空文本；样式取选区左上格；最终只保留新锚点记录。
- 合并后的内部网格线按合并区边界分段绘制，覆盖区域内部不保留残线。

### 5.3 工具条与拆分

- `jd-merge-cell` 和 `jd-split-cell` 位于 TableCell 工具条最左侧，按各自可执行性独立出现。
- 拆分移除选区内相交合并关系，锚点内容和样式保留，其他普通格恢复为空且继承 Table 默认样式。

## 6. TBL-015：标题

- 标题只保存为 `data.table.title`，为空时删除字段；标题不是独立 Shape，不参与网格尺寸、连接点和导出范围。
- Table 工具条通过事件通知对应 TableShape 进入标题编辑会话；双击标题进入编辑，点击标题可拖动整个 Table。
- 标题输入框随内容测量并自动扩宽。Overlay 容器默认禁用指针事件，标题编辑器显式恢复指针事件，使编辑态点击由原生输入框定位光标而不触发画布失焦保存。

## 7. TBL-016：Table 默认样式与单元格覆盖

- `defaultCellStyle` 是 Table 默认样式；单元格 `style` 仅保存与默认值不同的稀疏覆盖，覆盖消失时自然继承 Table 样式。
- 已完成样式包括背景、字号、文字颜色、文字背景色、水平与垂直对齐、加粗、斜体、下划线和删除线。
- Table 工具条修改默认样式，TableCell 或范围工具条修改覆盖。渲染、只读文字和 HTML 编辑器均通过同一有效样式解析，保证覆盖优先于默认值。

## 8. 验证与后续边界

- 相关领域、应用命令、工具条、编辑器和尺寸调整回归已纳入 Vitest；截至本次归档，`pnpm run test:unit` 通过 145 个文件、862 条测试，正式构建通过；全量类型检查仍受仓库既有错误阻断，本次涉及文件未发现新增类型错误。
- 当前已完成能力（含 TBL-017）已纳入现有实现边界；已有本地回归或用户自测证据按各项记录。仅 TBL-018 尚未完成，50×50 性能优化与基线结果暂不纳入已完成范围。
- 后续实现性能优化时，应先更新可执行规格的对应 TBL，再补充本文实现逻辑，不得以本文替代产品规则。
