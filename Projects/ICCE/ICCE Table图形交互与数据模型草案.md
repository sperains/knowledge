# ICCE Table 图形可执行规格

> 当前结论：Table 是一个独立画布图形，内部维护标题、行、列、单元格、合并关系和样式。本文是 Table 产品行为、数据不变量和验收要求的唯一事实来源，可直接作为后续架构设计、MVP 拆分和测试设计的输入。

> 事实来源：飞书画板人工操作与截图、2026-08-27 逐项确认的产品规则。实现进度与验收结果见第 12 节，稳定架构决策见第 13 节。

## 1. 目标与边界

### 1.1 功能目标

Table 在画布中作为一个整体参与选择、移动、尺寸调整、连接和 Region 包含，内部提供：

- 单元格文本编辑、键盘导航和批量粘贴。
- 行列新增、删除、重排和尺寸调整。
- 连续范围选择、单元格合并和取消合并。
- 可选标题。
- Table、范围和单元格三级样式作用域。

### 1.2 当前范围外

- 整个 Table 图形的专用复制粘贴规则；当前仅覆盖 Table 内部连续单元格范围的复制粘贴。
- Table 单元格的远端并发编辑和冲突处理。
- 虚拟滚动、局部渲染和单元格级协作协议。
- 单元格独立边框设置。

画布已有的通用能力是否自然覆盖上述项目，由架构与实现阶段另行验证，不作为本规格的 MVP 验收项。

### 1.3 撤销重做边界

- Table 不维护独立历史栈，也不设计单元格级撤销重做协议。
- 每次完成的持久化操作形成一次完整的 Table Shape 修改，并进入画布现有通用撤销重做机制。
- 一次单元格编辑提交、批量粘贴及自动扩容、行列增删或重排、合并或取消合并、尺寸拖拽结束以及样式修改，各自只形成一条历史记录。
- hover、选区、编辑焦点、编辑草稿和拖拽预览不进入历史记录。
- 撤销重做只恢复 Table 持久化数据，不恢复本地选区、hover 或编辑焦点。

### 1.4 术语

| 术语 | 定义 |
| --- | --- |
| 网格主体 | 由行、列和单元格组成的矩形区域，不包含标题 |
| Table 选中 | 画布选中对象仍是整个 Table，内部操作控件可见 |
| 当前单元格 | 单元格键盘导航和再次点击进入编辑的焦点位置 |
| 范围 | 连续框选的矩形单元格集合 |
| 合并锚点 | 合并区域左上角单元格，唯一保存合并后的内容和样式 |
| 行列关联组 | 为保持合并区域完整而需要一起重排的连续行组或列组 |
| 本地过程态 | hover、选区、编辑草稿、拖拽预览等不持久化状态 |

## 2. 默认参数

除非后续设计系统给出统一令牌，首版使用以下固定值：

| 项目 | 值 | 规则 |
| --- | --- | --- |
| 默认行数 | 3 | 新建 Table 初始化 3 行 |
| 默认列数 | 3 | 新建 Table 初始化 3 列 |
| 默认列宽 | 200 | 画布逻辑尺寸 |
| 默认行高 | 60 | 画布逻辑尺寸 |
| 默认网格尺寸 | 600×180 | 由 3×3 单元格尺寸求和得到 |
| 单元格内边距 | 8px | 自动适应内容时计入尺寸 |
| 标题字号 | 16px | 加粗，不随 Table 几何缩放改变 |
| 性能验证规模 | 50×50 | 2500 个单元格，首版完整渲染 |

单行和单列不设置产品级最小或最大尺寸；最终尺寸必须是有效正数。Table 网格宽高始终由所有列宽、行高求和得到。

## 3. Table 整体行为

### 3.1 默认态

- 只显示网格外框、内部网格线和单元格内容。
- 不显示整体选择框、行列灰条、插入点、尺寸控制线或上下文工具条。

### 3.2 整体选中态

选中 Table 后必须显示：

- 包围网格主体的蓝色选择框。
- 四个角缩放点，不显示外框侧边缩放点。
- 左上角 3×2 小圆点整体拖拽控制。
- 网格上方列控制条和左侧行控制条。
- Table 上下文工具条。

Table 内部单元格、范围或行列被选中时，画布对象身份仍然是该 Table。

单元格选中时仍保留 Table 作为画布对象选中身份，但隐藏不适用的整体选择视觉和快捷添加入口；Table 不提供四边快捷添加。

### 3.3 整体移动与缩放

- 拖拽左上角控制移动整个 Table。
- 四角缩放按同一比例调整全部列宽、行高和单元格几何尺寸。
- 单元格和标题文字字号不随 Table 几何缩放改变，只根据新单元格尺寸重新排版。
- 最后一列右边界和最后一行下边界仍可分别调整末列宽度和末行高度，Table 外框同步变化。
- 画布视口缩放沿用 ICCE 现有统一规则，不在 Table 内另设缩放协议。

### 3.4 画布集成

- Table 支持连线连接点，连接点附着网格主体，不包含标题。
- Table 放入 Region 后，其包含、移动、缩放和删除沿用其他图形的通用行为。
- 标题不计入网格选择框、连接点范围或导出范围。

## 4. 交互状态与焦点

### 4.1 状态定义

| 状态 | 进入条件 | 可观察表现 | 退出条件 |
| --- | --- | --- | --- |
| Table 默认 | 未选中 | 仅显示网格 | 点击 Table |
| Table 选中 | 首次点击 Table | 整体选择框、控制条和工具条可见 | Esc、点击空白或其他图形 |
| 单元格 hover | Table 已选中且指针进入单元格 | 浅蓝单元格边框 | 指针移出或更高优先级命中 |
| 单元格选中 | 点击单元格 | 明确蓝色单元格边框；Table 仍保持画布对象选中身份 | 选择其他目标、Enter 进入编辑或 Esc 清除单元格选中 |
| 多单元格选中 | Ctrl 点击多个单元格 | 多个离散单元格处于选中态 | 选择其他目标或 Esc |
| 范围选中 | 在单元格区域连续框选 | 矩形范围高亮 | 选择其他目标或 Esc |
| 单元格编辑 | 单元格选中后按 Enter | 编辑器和插入光标可见 | 提交、点击外部或 Esc 退出编辑 |
| 行列 hover | 指针进入灰条 | 点阵把手和整行整列浅蓝预览 | 指针移出 |
| 行列选中 | 点击灰条 | 整行整列强蓝色选中态 | 选择其他目标或 Esc |
| 插入预览 | hover 行列灰点 | 蓝色加号、贯穿线和提示 | 移出或完成插入 |
| 尺寸调整 | 拖拽行列边界 | 目标边界高亮并实时预览 | 指针释放或取消 |
| 行列重排 | 拖拽行列灰条 | 关联组和合法落点预览 | 指针释放或取消 |
| 标题编辑 | 添加标题或进入标题编辑 | 单行标题编辑器聚焦 | 提交、清空或转移焦点 |

### 4.2 命中优先级

同一指针位置存在多个候选时，按以下优先级处理：

1. 正在进行的编辑、尺寸调整或重排会话。
2. 行列灰条、尺寸边界和插入点。
3. 标题。
4. 单元格、范围和合并区域。
5. Table 整体选择与移动。

灰条 hover 时不叠加单元格 hover；尺寸边界和插入点使用各自独立热区。

### 4.3 点击与焦点转移

- 未选中 Table 时，首次点击只选中整个 Table。
- Table 已选中时，点击单元格进入单元格选中态。
- 单元格选中后按 Enter 进入编辑态；本阶段不把选中后的直接输入作为单独的编辑入口，中文输入法只在已经进入编辑态后处理。
- 编辑时点击其他单元格：保存当前内容、退出原编辑并选中新单元格。
- 编辑时点击 Table 外部：保存当前内容、退出编辑并取消 Table 选中，然后继续执行目标位置的画布选择。
- 点击画布空白处时，保存当前编辑内容并清除 Table 选中。
- 编辑态按 Esc 只退出编辑并回到当前单元格选中态，不产生本次编辑的正式提交；单元格选中态再次按 Esc 才清除单元格选中，Table 画布对象身份仍由画布层继续处理。
- 画布视口平移或缩放启动时会直接退出单元格编辑；编辑器不在手势期间实时跟随视口。

### 4.4 键盘规则

| 按键 | 单元格选中态 | 单元格编辑态 |
| --- | --- | --- |
| Enter | 进入当前单元格编辑 | 输入换行 |
| Tab | 选中下一个单元格；末格后回到第一格 | 先提交当前编辑，再选中下一个单元格；末格后回到第一格 |
| Ctrl + 点击 | 将目标加入离散多选 | 不适用 |
| Esc | 清除当前单元格选中，保留 Table 画布对象选中身份 | 退出编辑且不提交本次草稿，回到当前单元格选中 |
| Delete / Backspace | 清空当前单元格内容，不删除 Table | 由文本编辑器处理当前文本删除 |
| Shift + Tab | 不处理 | 不处理 |
| 方向键 | 选中相邻单元格，越过边界时保持当前位置 | 交由文本编辑器处理 |

Table 不增加独立 Esc 协议，必须接入 [[ICCE画布退出键分层取消设计]]。

## 5. 单元格内容与批量粘贴

### 5.1 文本编辑

- 单元格内容为支持换行的文本。
- 空单元格进入编辑时显示“输入文本”占位提示，占位提示不持久化。
- 文本自动换行。
- 编辑或粘贴导致内容高度不足时，目标行自动撑高，Table 外框同步扩张。
- 用户主动调整行高列宽时，以手动结果为准；双击边界可重新按内容自动适应。

### 5.2 批量粘贴

外部文本剪贴板从当前单元格开始解析：

1. 换行符划分行。
2. 制表符划分列。
3. 按从左到右、从上到下的行优先顺序填充。
4. 分隔符产生的空值是有效输入，必须清空对应目标单元格。
5. 超出现有范围时自动追加所需行列。
6. 自动追加的列宽为 200，行高为 60。
7. 自动追加的行列不继承合并关系。
8. 粘贴起点命中合并覆盖格时，按该合并区域的锚点作为起点；外部文本粘贴不复制合并关系，后续落入同一合并区域覆盖格的位置跳过写入。

ICCE 内部复制的连续单元格范围使用完整快照：

- 快照保留范围内单元格数据、行高、列宽和相对合并关系。
- 粘贴时按目标起点恢复行高和列宽；超出当前范围新增的行列先创建，再应用源范围尺寸。
- 粘贴前移除目标矩形内相交的合并关系，再按快照重建合并结构，避免新旧合并区域重叠。

## 6. 行列操作

### 6.1 控制条与插入入口

- 列灰条位于网格上方，行灰条位于网格左侧。
- Table 本体或所属 Region 悬停时可唤起行列控制条与插入入口；控制条只承载行列操作，不改变 Table 作为单一 Shape 的身份。
- 无标题 Table 在左上方显示 3×2 拖拽点阵，可直接拖拽整个 Table；有标题时沿用标题作为整体拖拽入口。
- 控制条保持方形并贴近网格；控制条舞台尺寸过小时隐藏控制条和左上角点阵，避免低缩放下产生视觉噪声。
- 列插入灰点与当前列右边界对齐；hover 后显示蓝色加号、纵向贯穿线和“插入列”提示。
- 行插入灰点与当前行下边界对齐；hover 后显示蓝色加号、横向贯穿线和“插入行”提示。
- 点击列插入点，在当前列右侧新增一列。
- 点击行插入点，在当前行下方新增一行。
- 左上角由首行和首列共用的灰点只用于在首行之前插入行。
- 不提供在首列之前插入列的入口。

### 6.2 新增继承

- 新增行继承上方相邻行的高度和内容样式。
- 新增列继承左侧相邻列的宽度和内容样式。
- 首行前插入使用 Table 默认行高和 Table 默认内容样式。
- 新单元格内容为空。
- 插入位置在合并区域外部时，新增行列不继承合并关系。
- 插入边界位于合并区域内部时，新行或新列必须并入该合并区域；锚点、内容和样式保持不变。
- 同一插入边界同时穿过多个合并区域时，所有跨越该边界的合并区域分别扩展。
- 新行或新列中落入扩展合并区域的位置是被覆盖单元格，不产生独立内容和样式。

### 6.3 删除

- 一次只能删除一行或一列，不支持批量删除多行或多列。
- 点击行或列控制条时只高亮对应控制条和行列范围，不将合并区域整体转为单元格选区。
- 行列选中时，上下文工具条显示对应的“删除行”或“删除列”入口；删除动作只作用于当前行或列。
- 可直接删除整个 Table。
- 删除到零行或零列时，等价于删除整个 Table。
- 删除不经过合并区域时，只移除目标行列。
- 删除经过合并区域但未删除锚点时，合并范围收缩，对应跨度减 1。
- 删除合并锚点所在行或列且仍有剩余范围时，内容和样式迁移到剩余范围的新左上角。
- 收缩后只剩 1×1 时，移除合并关系，内容和样式保留在该单元格。
- 合并区域所在维度被完全删除时，移除合并关系及其内容。
- 删除行或列后，优先选中删除位置左侧或上方的相邻行列；删除首行或首列时选中剩余的首行或首列；删除最后一行或列导致 Table 删除时清除选中状态。
- 插入行或列成功后清除单元格、行列选中状态，不自动选中新插入的内容。

### 6.4 手动调整与自动适应

- hover 行下边界时高亮整条横向边界，纵向拖拽只改变目标行高。
- hover 列右边界时高亮整条纵向边界，横向拖拽只改变目标列宽。
- 调整内部边界不压缩相邻行列，Table 外框同步扩张或收缩。
- 双击边界后，目标行列按内容自动适应并计入 8px 内边距。
- 合并单元格宽度等于所跨列宽之和，高度等于所跨行高之和。
- 合并内容需要的尺寸大于当前总尺寸时，自动适应产生的差额只增加到本次操作的目标行或目标列。

### 6.5 重排

- 拖拽列灰条重排列，拖拽行灰条重排行。
- 普通行列只移动自身，内容和样式随行列移动。
- 如果源行参与跨行合并，则递归收集所有相交合并区域涉及的行，直到行集合不再扩大，并将其作为一个行关联组移动。
- 如果源列参与跨列合并，则按相同规则形成列关联组。
- 关联组内部顺序保持不变，移动时携带整行或整列的所有单元格。
- 合并锚点、内容、样式和跨度在整体重排中保持不变，只更新关联组在行列顺序中的位置。
- 落槽由被拖拽行列组的中点是否越过目标块边界判断；目标边界进入另一个关联组内部时，以该组整体前边界或后边界确定落槽，不拆开合并区域。
- 目标落点位于当前移动组内部时，操作结果为无变化。
- 拖拽期间不改变表格实际顺序，显示跟随指针移动的影子和单条略粗于插入预览的高亮线；高亮线表示最终落槽边界，释放后源组紧跟在线前方行列之后。
- 拖拽开始时选中当前行列，拖拽期间操作条选中状态保持不变；只有释放后才提交行列重排，取消则恢复原数据。

## 7. 合并与取消合并

### 7.1 合并

- 普通连续范围显示“合并单元格”动作。
- 选区包含已有合并区及周边单元格时，合并动作将选区内已有合并区原子地重组成覆盖整个选区的新合并区；不要求用户先拆分再合并。
- 合并与拆分是相互独立的动作：两者均可执行时同时显示在 TableCell 工具条最左侧；选区恰好等同于一个合并区时不显示重复合并动作。
- 合并结果锚点固定为范围左上角。
- 从左上角开始，按照从左到右、从上到下的行优先顺序遍历内容。
- 跳过空字符串；多个非空内容使用一个换行符连接，不去重、不重新排序、不自动添加标点。
- 合并后的背景色、字号、文字颜色和对齐方式统一使用首格样式。
- 合并结果只保存在锚点；其他覆盖单元格内容清空并恢复继承样式。

### 7.2 取消合并

- 范围只要与已有合并区域相交，工具条就显示“取消合并”。
- 指针命中合并覆盖格时，当前范围按完整合并区扩展；拆分后仍保留拆分前完整展开的矩形选区，不能因锚点地址回退而缩小选区。
- 一次框选相交多个合并区域时，取消全部相交区域的合并关系。
- 取消合并后，内容和样式只保留在原锚点；其他恢复单元格为空并使用继承样式。

### 7.3 合并不变量

- 合并区域始终是连续矩形。
- 锚点始终是合并区域当前左上角。
- 内容和样式始终只有一份。
- 跨度必须等于当前合并区域覆盖的有效行数和列数。
- 删除通过收缩范围和必要的锚点迁移维持不变量。
- 重排通过关联组整体移动维持不变量，不允许产生非连续合并区域。

## 8. 标题

- Table 上下文工具条提供“添加标题”。
- 添加后标题位于网格左上方并与网格左边缘对齐，不占用第一行。
- 添加标题后自动聚焦，初始内容为空字符串。
- 标题为空时不持久化标题可见状态，并恢复显示 3×2 小圆点 Table 拖拽控制。
- 不提供独立删除标题动作；双击标题进入编辑并删除全部文本即可移除标题。
- 标题不换行，宽度不受网格宽度限制。
- 标题固定为 16px 加粗，不随 Table 几何缩放改变。
- 点击标题选中整个 Table，拖拽标题移动整个 Table，行为与 ICCE Region 标题一致。
- 标题编辑框宽度按当前内容测量并自动扩展；双击标题进入编辑，已处于编辑态时点击输入框只移动光标位置。
- 标题跟随 Table 移动和删除，但不建成独立 Shape。

## 9. 样式作用域

| 当前目标 | 样式作用范围 |
| --- | --- |
| Table 整体 | 更新 Table 默认单元格背景、字号、文字颜色、文字背景色、四项文字样式和对齐方式 |
| 连续范围或离散多选 | 为所有目标单元格写入样式覆盖 |
| 单个单元格 | 为当前单元格写入样式覆盖 |

其他规则：

- Table 网格边框只支持颜色，不支持单独设置粗细和线型。
- 边框颜色、背景色、字号、文字颜色、文字背景色、加粗、斜体、下划线、删除线和对齐方式复用现有上下文菜单。
- 单元格背景、字号、文字颜色、文字背景色、四项文字样式和对齐方式覆盖 Table 默认值。
- 清除单元格或范围背景覆盖时，删除对应覆盖值并恢复继承 Table 默认背景。
- 首版不支持单个单元格独立边框。

## 10. 逻辑数据约束

### 10.1 持久化数据

Table 持久化数据放在同一个 Table Shape 的 `data.table` 中，使用带版本号的稀疏单元格模型：

```ts
interface TableDataV1 {
  schemaVersion: 1;
  title?: string;
  borderColor: string;
  defaultCellStyle: TableCellStyle;
  rows: Array<{ id: string; height: number }>;
  columns: Array<{ id: string; width: number }>;
  cells: Record<RowId, Record<ColumnId, TableCell>>;
  merges: TableMerge[];
}

interface TableCell {
  text: string;
  style?: Partial<TableCellStyle>;
}

interface TableMerge {
  anchor: { rowId: string; columnId: string };
  rowIds: string[];
  columnIds: string[];
}
```

- `title` 仅在存在非空标题时保存，不保存独立标题可见状态。
- `borderColor` 和 `defaultCellStyle` 分别表达 Table 网格边框颜色和单元格默认样式。
- `rows` 和 `columns` 是唯一的显示顺序来源，并保存稳定 ID 与尺寸。
- `cells` 以行列 ID 定位；只有非空内容或存在样式覆盖的普通单元格才保存记录。
- `merges` 独立保存合并锚点和参与合并的有序行列 ID；行列跨度由 ID 数量推导，不重复持久化跨度数字。
- `schemaVersion` 用于后续数据模型演进。

### 10.2 身份与尺寸

- 行列身份使用稳定 ID，数组位置只表示当前显示顺序。
- 单元格身份由行 ID 和列 ID 唯一确定。
- 行列插入、删除和重排不得用易变索引代替持久化身份。
- 网格宽度等于所有列宽之和，网格高度等于所有行高之和。
- Table Shape 的 `width` 和 `height` 分别与列宽、行高求和保持一致，由同一次应用命令原子更新。
- 标题不计入网格宽高。

### 10.3 样式与合并

- Table 保存默认单元格样式，单元格只保存覆盖值。
- 空内容且无样式覆盖的单元格不保存记录；空内容但存在样式覆盖时仍保存记录。
- 被合并覆盖的单元格不保存 `cells` 记录，也不保存指向锚点的 `coveredBy` 类冗余字段。
- 合并区域内容和样式只由逻辑锚点承担；当锚点也是空内容且无样式覆盖时，可以只保存合并关系。
- 渲染和命中阶段根据 `merges` 构造本地覆盖索引，将被覆盖坐标解析到锚点；该索引不持久化。
- 合并操作删除范围内原有单元格记录，把合并后的内容和首格样式写入锚点，并创建一条合并关系。
- 取消合并只删除合并关系并保留锚点记录，其他位置因没有单元格记录而恢复为空。
- 取消合并或删除导致恢复的普通单元格默认为空并继承 Table 样式。

### 10.4 数据不变量

- 行 ID 和列 ID 在各自集合内唯一，所有单元格和合并关系只能引用存在的行列。
- 合并区域在当前行列顺序中必须连续且为矩形，不同合并区域不得重叠。
- 合并锚点必须是合并区域当前的左上角。
- 不保存 1×1 合并关系，也不允许被合并覆盖位置存在单元格记录。
- Table Shape 外框尺寸必须与行列尺寸求和一致。

### 10.5 本地过程态

以下状态不得写入持久化数据：

- hover 的单元格、行、列和插入点。
- 当前单元格、离散多选和连续范围。
- 编辑草稿与编辑器焦点。
- 尺寸调整、重排和插入预览。
- 上下文菜单和工具条弹层状态。

## 11. ICCE 实现约束

- Table 是一个 Shape，位置、尺寸、层级、选择和通用画布行为复用 Shape 外层模型。
- Table 内部行列和单元格不创建独立 Shape，也不进入 CanvasRelation。
- Table 放入 Region 时，只使用现有关系表达 Region 包含 Table。
- 持久化修改必须通过应用命令产生同一个 Table Shape 的修改变更，不直接写 Store。
- 单元格编辑输入过程通过 `table-cell-edit` 协作交互消息同步文本和目标行高，远端只投影临时预览；保存时再以一次正式 Shape 修改提交，取消时发送重置消息。
- 拖拽、重排和尺寸调整使用本地预览，完成时沿用 Plan → Commit → ChangeSet → Publish 边界单次提交。
- 历史记录粒度与本地过程态的回放边界遵循第 1.3 节；实现不另设 Table 历史栈。

### 11.1 渲染分层

- Table 网格、单元格背景、边框、文字和只读标题由 MainLayer 中的 Table 渲染器承载，并遵守 Shape 的层级和遮挡关系。
- Table 主体使用 Konva 批量绘制，不为每个单元格创建独立 Shape 或完整场景节点组。
- 单元格命中由 Table 局部坐标、累计行高和累计列宽计算，并通过本地合并覆盖索引解析锚点，不依赖单元格场景节点。
- 行列重排、插入和尺寸调整的未提交视觉放入 LocalPreviewLayer，不直接修改持久化 Store。
- Table 整体选择框、四角控制点、单元格与范围高亮、行列灰条、插入入口和尺寸调整热区放入 SelectionLayer 的 Table 专用交互覆盖物。
- Table 连接点仍由 SelectionLayer 的连接点层承载，附着网格主体而不包含标题。
- 上下文工具条、颜色面板和提示气泡继续使用现有 DOM 浮层。

### 11.3 Table 专用上下文工具条

- Table 和 TableCell 复用现有浮动工具条、控件和弹窗外壳，但按目标作用域生成独立工具条模型。
- Table 整体目标只提供添加或编辑标题、字号、四项文字样式、文本对齐、表格边框、默认单元格背景、文字颜色、文字背景色、层级和删除；不显示图形类型切换。
- TableCell 或连续范围目标只提供合并、拆分、字号、四项文字样式、文本对齐、单元格背景、文字颜色和文字背景色；合并与拆分按可执行性独立显示，不显示图形类型切换、层级和删除。
- 单元格工具条的定位边界使用当前单元格或连续范围的合并感知边界，不改变 Table 作为唯一画布 Shape 的身份。
- Table 整体样式写入 `defaultCellStyle`，单元格或范围样式写入稀疏单元格覆盖；合并、取消合并和样式修改均通过完整 Table Shape 更新提交。
- 标题入口只切换标题编辑会话，标题文本为空时删除标题字段，不保存独立标题 Shape 或可见状态。

### 11.2 编辑器承载

- 单元格和标题编辑复用画布 HTML Overlay，只挂载当前活动的一个 DOM 编辑器，不为所有单元格常驻创建 DOM。
- 单元格使用支持换行、自动折行、文本选择、中文输入法和剪贴板读取的多行编辑器；标题使用单行编辑器。
- 活动单元格编辑器的文本水平与垂直对齐必须读取同一份单元格有效样式；默认中间对齐时，编辑态与 Konva 显示态均保持居中。
- 只读 Konva 文本与 HTML 编辑器必须使用同一字体族、普通字重和字形；当前默认字体栈为 `Noto Sans, HarmonyOS Sans SC, sans-serif`。
- HTML Overlay 容器默认不接收指针事件，仅当前活动编辑器开启指针事件。
- 单元格选中态的 HTML 编辑器覆盖层不接收指针事件；Tab 导航必须由单元格交互优先消费，不得落入上下文工具条的焦点序列。
- 打开单元格编辑器时，按当前画布视口将 Konva 单元格坐标、尺寸、内边距和字号换算为 HTML Overlay 的样式快照，保证编辑态与显示态对齐。
- HTML Overlay 的视口快照和退出规则按第 4.3 节执行；Table 四角几何缩放只改变行列尺寸，不改变字号数据。
- 四角控制点、行列灰点、插入加号、拖拽图标和尺寸调整热区保持屏幕像素尺寸，不随画布缩放改变操作尺寸。
- Table 主体不长期渲染到 HTML Overlay，避免 DOM 始终位于 Konva Stage 上方而破坏 Shape 层级、遮挡、导出和统一命中。
