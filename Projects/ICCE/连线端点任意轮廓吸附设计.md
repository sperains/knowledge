# 连线端点任意轮廓吸附设计

## 1. 背景与目标

当前连线端点仅支持连接到图形 `top`、`right`、`bottom`、`left` 四条边的中点。

本次仅扩展端点吸附能力：

- 连线创建和端点重连时，端点可以落在图形轮廓上的任意位置。
- 保留现有四边中点，指针靠近中点时优先精确吸附到中点。
- 不调整现有正交路由、箭头、连线样式和中间线段编辑规则。

## 2. 范围

### 2.1 本次包含

- 矩形类图形任意轮廓位置投影。
- 椭圆图形任意轮廓位置投影。
- 菱形图形任意轮廓位置投影。
- 四边中点强吸附。
- 创建连线与端点重连复用同一套吸附计算。
- 图形移动或缩放后，根据保存的归一化轮廓位置重新解析端点坐标。
- 旧数据兼容、快照回放和协同数据透传。

### 2.2 本次不包含

- 改造正交路由策略。
- 自动绕障碍能力调整。
- 连线圆角效果调整。
- 自由端点。
- 用户手动切换端点进出方向。
- 为任意轮廓位置常驻渲染连接点。

## 3. 术语

- **中点锚点**：现有 `top`、`right`、`bottom`、`left` 四个连接点。
- **轮廓落点**：指针投影到图形真实轮廓后得到的画布坐标。
- **归一化轮廓位置**：轮廓落点在图形局部包围盒中的比例坐标。
- **进出方向**：正交线从端点离开或进入图形的水平、垂直方向，继续使用现有 `anchor` 表示。

## 4. 交互规则

拖动新连线或重连端点时，按照以下优先级解析目标：

1. 找到指针命中的可连接图形。
2. 计算指针到四个中点的距离。
3. 指针进入中点强吸附范围时，端点精确落在对应中点。
4. 未命中中点时，将指针投影到图形轮廓的最近位置。
5. 指针位于图形内部，或指针到轮廓的距离不超过轮廓吸附范围时，使用该轮廓落点。
6. 未满足上述条件时不吸附。

中点吸附优先级高于普通轮廓吸附。拖动过程中展示现有中点状态；普通轮廓落点只展示一个临时吸附点。

## 5. 吸附距离

吸附距离使用屏幕像素，再根据画布缩放换算为 stage 距离：

```ts
const MIDPOINT_SNAP_DISTANCE_SCREEN_PX = 12;
const OUTLINE_SNAP_DISTANCE_SCREEN_PX = 20;

const stageDistance = screenDistance / viewportScale;
```

中点进入吸附范围后，应优先保持当前中点，避免与普通轮廓落点频繁切换。第一期复用当前交互会话中的目标位置实现稳定选择，不新增持久化状态。

## 6. 数据模型

`anchor` 继续表示正交线进出方向，新增独立字段保存任意轮廓落点：

```ts
interface BoundaryPosition {
  xRatio: number;
  yRatio: number;
}

interface LineEndpoint {
  shapeId: string;
  anchor: Edge;
  boundaryPosition?: BoundaryPosition;
  normal?: OrthogonalNormal;
}
```

约束：

- `xRatio`、`yRatio` 使用图形局部包围盒归一化坐标。
- 新创建或重新连接的端点写入明确的 `boundaryPosition`。
- 旧数据缺少 `boundaryPosition` 时，仍按照 `anchor` 对应的边中点解析。
- 读取旧数据时不自动回填或持久化新字段。
- `boundaryPosition` 与 `anchor` 职责独立，不使用其他字段冒充轮廓位置。

四个中点的归一化位置为：

| anchor | boundaryPosition             |
| ------ | ---------------------------- |
| top    | `{ xRatio: 0.5, yRatio: 0 }` |
| right  | `{ xRatio: 1, yRatio: 0.5 }` |
| bottom | `{ xRatio: 0.5, yRatio: 1 }` |
| left   | `{ xRatio: 0, yRatio: 0.5 }` |

## 7. 几何计算

统一提供两个领域能力：

```ts
function projectPointToShapeOutline(shape: Shape, point: Point): OutlineProjection;

function resolveLineEndpointPoint(shape: Shape, endpoint: LineEndpoint): Point;
```

`OutlineProjection` 包含：

```ts
interface OutlineProjection {
  point: Point;
  boundaryPosition: BoundaryPosition;
  anchor: Edge;
  distance: number;
}
```

### 7.1 矩形类

计算指针到四条边线段的最近点，选择欧氏距离最小的候选。落点所属边直接作为 `anchor`。

### 7.2 椭圆

将指针转换到椭圆局部坐标，计算椭圆轮廓上的投影点。使用投影点的椭圆外法线主方向解析 `anchor`：

- 水平分量绝对值更大时选择 `left` 或 `right`。
- 垂直分量绝对值更大时选择 `top` 或 `bottom`。

### 7.3 菱形

将菱形轮廓视为四条线段，分别计算最近投影点。根据投影线段外侧方向的主分量解析 `anchor`。

### 7.4 端点坐标恢复

- 有 `boundaryPosition`：根据图形当前包围盒恢复局部坐标，再投影回对应图形轮廓，避免浮点或缩放误差导致端点离开轮廓。
- 无 `boundaryPosition`：使用现有 `anchor` 中点。

## 8. 正交线衔接

正交路由的输入端点由原来的固定中点改为实际轮廓落点：

```text
实际轮廓落点 → 按 anchor 生成端点 stub → 现有正交路径
```

- `boundaryPosition` 决定实际坐标。
- `anchor` 决定端点 stub 的水平或垂直方向。
- 本次不修改后续路由算法。

## 9. 创建与重连流程

### 9.1 创建连线

1. 从现有四中点开始连线，起点写入对应中点的归一化位置。
2. 拖动到目标图形时实时计算中点或任意轮廓吸附结果。
3. 使用吸附结果实时生成预览路径。
4. 松手后将两端 `anchor` 和 `boundaryPosition` 写入连线。

### 9.2 端点重连

1. 未拖动的一端使用已有 `boundaryPosition` 恢复实际坐标。
2. 被拖动的一端使用与创建连线相同的吸附计算。
3. 松手后只更新被重连端点的 `shapeId`、`anchor` 和 `boundaryPosition`。

## 10. 视觉状态

- 四个中点继续使用现有空心/实心状态。
- 普通轮廓吸附时显示临时蓝色实心点。
- 临时点尺寸保持屏幕像素稳定。
- 交互取消或完成后立即清除临时点。

## 11. 兼容与同步

- 快照适配器保留合法的 `boundaryPosition`，缺失时保持缺失。
- 协同消息沿用完整 `LineEndpoint` 透传新字段。
- 创建、重连、撤销、重做和回放均以完整端点对象为准。
- 非法或非有限数值的 `boundaryPosition` 按缺失处理，不使用其他字段补齐。

## 12. 验收标准

1. 连线端点可以落在矩形类图形四条边的任意位置。
2. 连线端点可以落在椭圆和菱形轮廓的任意位置。
3. 靠近四边中点时优先精确吸附到中点。
4. 离开中点范围后恢复普通轮廓吸附。
5. 创建连线与端点重连的吸附规则一致。
6. 拖动预览点、预览连线和最终保存位置一致。
7. 图形移动、缩放后端点仍保持原相对轮廓位置。
8. 不同画布缩放级别下吸附距离体验一致。
9. 正交线首末端方向继续由 `anchor` 正确约束。
10. 旧连线缺少 `boundaryPosition` 时仍连接到原四边中点。
11. 快照、撤销重做和协同回放后端点位置一致。

## 13. 实施顺序

1. 扩展端点模型和快照归一化。
2. 实现轮廓投影、端点恢复和中点强吸附领域函数。
3. 扩展连接交互会话，使其携带完整吸附端点。
4. 接入创建连线预览与提交。
5. 接入端点重连预览与提交。
6. 接入图形移动、缩放后的连线端点刷新。
7. 增加临时轮廓吸附点视觉反馈。
8. 补充领域、交互、快照和集成验证。

## 14. 当前实现补充（2026-08-10）

> 状态：已落地

第 2.2 节中的“本次不包含改造正交路由策略、自动绕障能力调整”属于原始方案范围，保留作为历史记录。后续实现已经补充正交路由和自身图形避障，以下内容作为当前有效实现说明。

### 14.1 预览与落地共用路由入口

- 新建连线、重连吸附预览和最终落地统一通过 `buildConnectionLineDraft` 生成连线草稿。
- `routeConnectionLineDraft` 统一解析真实端点坐标、端点方向和起终点图形包围盒，预览与落地使用相同几何输入。
- 重连预览始终从重连开始时保存的基准路径派生，连续移动指针不会叠加修改上一帧路径，避免路径漂移。

### 14.2 路由模式与手动路径边界

- `data.routeMode` 只有 `auto` 和 `manual` 两种取值。
- 缺少 `routeMode` 的历史连线按 `auto` 处理，不再根据折点形态推断用户是否编辑过。
- 自动路由或重新规划后的路径显式写入 `auto`；控制点拖动后的路径显式写入 `manual`。
- `auto` 模式在端点移动或重连时完整重算路径。
- `manual` 模式优先保留用户编辑的中间折点，只调整受端点影响的首尾连续链；如果保留结果穿过端点图形或产生端点往返折点，则回退到自动路由，以正确性优先。

### 14.3 正交自动路由优先级

自动路由按以下顺序选择路径：

1. 生成端点外法向短引线和端点中线的首选路径。
2. 首选路径穿过图形或在端点折返时，尝试图形实际包围盒之间的间隙中线。
3. 间隙中线优先使用起点法向对应的空间分离轴；该轴没有间隙时，改用另一条分离轴，覆盖上出左进等交叉方向。
4. 以上候选均不可用时，使用由端点、候选折点和安全边界组成的稀疏正交网格寻路。

间隙中线以两侧图形边界的间隙中点为基准，而不是以连线两端坐标的中点为基准，因此图形尺寸不同或端点位置偏离中心时，路径仍保持图形之间的居中效果。

### 14.4 自身图形避障约束

- 起点和终点图形的实际包围盒作为碰撞边界，连线不得穿过两个图形的内部。
- 图形边界允许被连线贴边经过；端点与所属图形边界的接触不视为穿越。
- 安全边界在实际包围盒外扩默认 16 个画布单位，只用于计算端点短引线和网格候选轴，不改变实际碰撞边界。
- 端点第一段必须沿起点外法向离开，最后一段必须沿终点外法向进入，禁止短引线反向折返。
- 网格寻路以曼哈顿距离为基础，同时增加折点代价，优先选择距离接近且折点更少的路径；同一坐标轴只连接相邻可见节点，保持路径稳定并减少无必要的节点比较。

### 14.5 路径数据与编辑不变量

- 正交路径点按“起点锚点、起点短引线、中间折点、终点短引线、终点锚点”顺序保存。
- 存储路径、渲染路径和控制点路径通过统一规范化逻辑转换，连续重复点和无语义共线点可以清理，但首尾锚点必须保留。
- `anchor` 负责端点的水平或垂直进出方向，`boundaryPosition` 负责图形轮廓上的实际落点，两者职责独立。
- 已有旧连线不会通过数据迁移批量重算；缺少路由模式的旧连线会在新建、重连或端点更新等重新规划时使用当前自动路由。

## 15. 当前实现影响

- 新建连线和吸附重连的预览路径与最终落地路径保持一致。
- 自动连线在端点图形尺寸不同、空间投影重叠或端点方向交叉时，优先选择图形间隙中的稳定折点。
- 手动编辑路径在重连时可以保留用户意图，但当路径违反自身避障或端点方向约束时会自动重新规划。
- 路由核心实现和维护注释位于 `src/views/icce/domain/services/orthogonal-line-model.ts`，交互草稿统一入口位于 `src/views/icce/ui/tools/line/line-interaction.ts`。
