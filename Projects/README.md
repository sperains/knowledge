## 项目目录规则

- 每个具体项目使用 `Projects/项目名/` 独立收纳。
- 项目入口文档统一使用 `MOC.md`，负责维护项目内的知识导航。
- 项目专属 ADR 放在项目目录下的 `ADR/` 中，各项目独立编号；引用时使用完整项目路径，避免不同项目的编号产生歧义。
- 跨项目的工作记录、AI 提示词和知识库全局规则保留在根目录；日报和月报统一归入 `Worklog/`。
- 新增项目时，先创建项目目录和 MOC，再添加具体设计文档。
