# LowCode

简易低代码项目的技术选型、最小架构、目录规范、数据库设计和演进边界。

## 文档导航

- [[简易低代码项目技术选型与目录设计]]：记录项目的推荐技术栈、最小系统架构、目录组织方式和后续演进原则。
- [[数据库设计]]：记录项目、页面、页面版本和项目配置的数据库模型、页面 JSON 结构及迁移规范。
- [[页面编辑器与预览闭环]]：记录当前页面管理、页面编辑器、页面预览、路由和页面配置的落地状态。
- [[页面类型选择与关联设计]]：记录列表页和表单页的类型选择时机、访问路径及页面关联规则。
- [[ADR/MOC|架构决策记录]]：记录项目中需要长期遵守的架构选择、取舍和演进约束。

## 文档职责

- `MOC.md` 只负责项目导航和当前结论摘要。
- `ADR/` 只记录已经确认的长期架构约束。
- 项目根目录的设计文档负责当前功能、数据模型和技术方案说明。
- 尚未确认的方案和后续演进边界保留在设计文档中，不写入 Accepted ADR。

## 当前结论

以下内容是 LowCode 当前项目基线；具体架构取舍以 [[ADR/MOC|架构决策记录]] 为准，详细实现以对应设计文档为准。

- 前端采用 Vue 3、TypeScript 和 Vite。
- 界面组件库采用 Arco Design Vue。
- 后端采用 FastAPI，保持单体应用结构。
- 早期使用 SQLite 保存项目、页面和页面版本配置。
- 页面配置以 JSON 形式保存组件树、属性和样式。
- 数据库结构使用 SQLModel 描述，并通过 Alembic 管理迁移。
- 项目目录使用 `apps/web` 和 `apps/api`，不使用笼统的 `frontend` 和 `backend`。
- 第一阶段不引入微服务、缓存、消息队列和复杂权限体系。
- 低代码配置通过自定义组件元数据层承接，不直接暴露组件库的全部属性。
- 页面编辑器已经打通组件添加、属性修改、页面保存和页面预览的最小闭环。
- 列表页配置使用 JSON 保存页面标题、简介、筛选条件、工具栏、表格列、行操作和分页设置。
- 列表页编辑器与预览聚焦筛选工具栏和数据内容，页面内部不重复显示 Header；筛选字段过多时自动换行。
- 桌面端预览使用最大宽度 1120px 的自适应容器，不强制使用 16:9 比例；移动端使用约 390px 宽度。
- 编辑器采用沉浸式布局，隐藏项目中心导航；预览页使用独立布局展示已保存页面。
- 编辑器和预览共用组件渲染器，保持配置结构和展示结果一致。
- 页面类型暂时只区分列表页和表单页，在创建页面时确定，编辑器不提供普通类型切换。
- 列表页通过页面编号关联表单页，表单页同时支持新建和编辑模式。
- 表单页保留访问路径但默认不显示在主菜单中。
