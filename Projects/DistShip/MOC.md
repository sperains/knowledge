# DistShip 项目知识地图

DistShip 是面向 macOS 和 Linux 的静态前端项目本地构建与 SSH 增量部署工具，当前定位于自有测试和预发布环境。

## 当前状态

可靠部署主路径已经完成并通过首个真实项目验收；第二个真实项目验证、GoReleaser、GitHub Release 和 Homebrew Tap 是当前剩余主线。
