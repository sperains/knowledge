# 通用关系树选择组件需求

## 1. 背景

jd_ipd 的 `ParamDesc.vue` 在“参数名称”字段中使用关系树选择器。关系接口返回关系对象，树节点位于 `children` 中；表单保存的是选中的节点对象。

实际业务中，关系树会发生变化，已保存的节点可能从最新树中消失，但历史值仍然需要回显。输入框还需要展示节点的颜色、背景色和路径信息，并支持实际选中层级与显示层级分离。

因此，jd-ui 需要提供一个可以被多个业务系统复用的 `jd-relation-select-java`。原有 `jd-relation-select` 不在本需求范围内。

## 2. 目标

- 提供统一的关系树选择能力。
- 每次打开下拉都获取最新关系树。
- 保证当前节点和历史节点都可以正常回显。
- 支持根节点、中间节点和叶子节点选择。
- 支持单选、多选、文本显示和路径显示。
- 让使用方拿到结构一致、不包含 `children` 的节点值。
- 将业务字段联动、业务校验和提示组件留在使用方。

## 3. 非目标

- 不处理参数名称、参数描述、输入输出分组等业务语义。
- 不修改 jd_ipd 的 `ParamDesc.vue` 和原有关系选择组件。
- 不在组件内部直接调用业务系统的全局弹窗。
- 不支持接口直接返回节点数组。
- 不提前引入跨系统字段映射和业务字段适配层。

## 4. 功能需求

### FR-01 每次打开获取最新数据

每次下拉面板从关闭状态变为打开状态时，都必须调用一次 `getDataFn`。

即使 `relationNo` 没有变化，也不能复用上一次打开时的数据。每次请求成功后，使用本次响应替换内部下拉树；空响应需要清空旧树。

后发请求完成后，先发请求的结果不能覆盖后发请求的结果。

### FR-02 关系对象响应

接口必须返回关系对象，树节点位于 `children`：

~~~ts
interface RelationResponse {
  id: number | string;
  business_no: string;
  relation_name: string;
  work_number?: string;
  user_name?: string;
  children: RelationNodeData[];
}
~~~

`getDataFn` 可以返回 `RelationResponse`、`null` 或 `undefined`：

~~~ts
type GetDataFn = (relationNo: string) => Promise<RelationResponse | null | undefined>;
~~~

### FR-03 空数据和请求异常

| 情况 | 结果 | 事件 |
| --- | --- | --- |
| 返回有效关系对象且 `children` 有数据 | 加载最新树 | 无 |
| 接口整体返回 `null` 或 `undefined` | 清空内部树，保留历史值 | `load-empty`，`reason: 'empty-response'` |
| 返回关系对象但 `children: []` | 清空内部树，保留历史值 | `load-empty`，`reason: 'empty-children'` |
| 请求抛出异常 | 结束加载，保留当前值 | `load-error` |
| 响应缺少 `children` 数组 | 清空内部树，保留历史值 | `load-empty`，`reason: 'empty-children'` |

组件只负责发出事件。使用方决定提示文案、提示组件和提示频率。

### FR-04 历史值回显

如果初始值在最新树中仍然存在：

- 使用最新节点的文本、样式和业务字段。
- 重新生成最新的 `paths`。
- 从对外值中移除 `children`。

如果初始值已经不存在：

- 不清空历史 `v-model`。
- 继续显示历史文本和完整路径。
- 保留历史路径节点各自的颜色、背景色和边框色。
- 保留历史节点的图标、描述和其他业务字段。
- 已知字段缺失时补充空值。

只有用户重新选择或主动清空时，历史值才会被替换或移除。

### FR-05 统一值结构

单选模式的 `v-model` 是一个节点对象，未选择时为空值。多选模式的 `v-model` 是节点对象数组，未选择时为空数组。

选中值不能包含 `children`，必须包含节点路径：

~~~ts
interface RelationValue extends RelationNodeData {
  children?: never;
  paths: RelationPathNode[];
}
~~~

`paths` 是节点对象数组，不是文本数组。每个路径节点保留自己的文本、颜色、背景色和边框色。

### FR-06 任意层级选择

组件默认仅允许选择叶子节点；显式设置 `allowParentSelect=true` 后才允许选择任意层级：

- 根节点可选。
- 中间节点可选。
- 叶子节点可选。

当 `allowParentSelect=false` 时，父节点只能展开或收起，不能更新 `v-model`；叶子节点仍然可以选择。`disableLevels` 可以进一步禁止指定层级选择，但不影响这些节点展开。

搜索命中父节点时，需要保留其后代节点，使父节点仍然可以展开。

### FR-07 单选与多选

单选模式选择新节点时替换旧值，主动清空后回写空值。

多选模式要求：

- 默认展示所有已选标签。
- 每个已选节点可以单独移除。
- 设置 `max-tag-count` 后，超出部分显示 `+N`。
- 搜索输入紧邻已选标签。
- 路径模式下，每个选中项使用一个整体路径标签包裹。

### FR-08 文本和路径显示

`displayMode` 默认为 `text`：

- 文本模式显示指定层级的节点文本。
- 路径模式显示从根节点到指定层级的路径。

`separator` 默认为 `->`，显示时分隔符左右保留空格：

~~~text
输入 -> IN -> 环境 -> 温度
~~~

### FR-09 指定显示层级

`displayLevel` 从 1 开始，只改变输入框显示，不改变实际选中节点和提交值：

| 配置 | 文本模式 | 路径模式 |
| --- | --- | --- |
| 未指定或小于 1 | 末级文本 | 完整路径 |
| `1` | 第一级文本 | 第一级路径 |
| `2` | 第二级文本 | 前两级路径 |
| `N` | 第 N 级文本 | 前 N 级路径 |

实际选中四级节点“输入 -> IN -> 环境 -> 温度”，设置 `displayLevel: 2` 后，文本模式显示“IN”，路径模式显示“输入 -> IN”，`v-model` 仍保存四级节点和完整 `paths`。

### FR-10 节点视觉样式

下拉树和输入框读取节点的：

- `color`：文字颜色。
- `bg_color`：背景色。
- `border_color`：边框色。
- `node_icon`：节点图标。

路径模式下，每个路径节点使用自己的样式；历史值使用历史快照中的样式。

### FR-11 插槽

组件提供以下插槽：

| 插槽 | 用途 |
| --- | --- |
| `trigger` | 完全替换默认输入框触发器 |
| `node-title` | 自定义下拉树节点内容 |
| `node-label` | 自定义默认输入框中的节点文本 |

使用 `trigger` 插槽时，使用方需要自行处理展示、清空、移除和交互反馈。

## 5. 业务边界

ParamDesc.vue 只负责使用组件，并处理自身业务：

- 将选中节点的 `word_describe` 写入参数描述。
- 根据路径和节点文本判断输入、输出等业务分组。
- 参数行移动、表单校验和提交字段转换。
- 处理关系数据为空或请求失败后的业务提示。

通用组件不感知这些业务概念。

## 6. 对外接口

### 6.1 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `relationNo` | `string` | 必填 | 请求关系数据使用的关系编号 |
| `getDataFn` | `GetDataFn` | 必填 | 请求关系对象 |
| `multiple` | `boolean` | `false` | 是否多选 |
| `displayMode` | `'text' \| 'path'` | `'text'` | 输入框显示文本或路径 |
| `displayLevel` | `number` | 未指定 | 输入框显示层级 |
| `separator` | `string` | `'->'` | 路径分隔符 |
| `allowParentSelect` | `boolean` | `false` | 是否允许选择父节点 |
| `disableLevels` | `number[]` | `[]` | 从根节点开始按 1 计算的禁选层级；不影响展开 |
| `nodeIconSize` | `number` | `20` | 节点图标尺寸 |
| `size` | Arco 尺寸枚举 | `'large'` | 输入框尺寸 |
| `showBorder` | `boolean` | `false` | 是否显示完整边框 |

组件同时透传 Arco 树选择器的 `allow-search`、`allow-clear`、`max-tag-count`、`placeholder` 和 `disabled` 等常用属性。

### 6.2 事件

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| `update:modelValue` | 节点或节点数组 | 双向绑定值变化 |
| `change` | `value, node` | 用户选择或清空后的值变化 |
| `search` | 搜索文本 | 搜索输入变化 |
| `load-empty` | `{ relationNo, reason, response }` | 请求成功但没有可用节点 |
| `load-error` | `{ relationNo, error }` | 请求异常 |

`load-empty.reason` 只有 `empty-response` 和 `empty-children` 两种值。

初始化历史值、打开下拉后的自动匹配不会主动触发业务性的 `change`。

## 7. 验收标准

1. 每次打开下拉都请求最新关系树，关系编号不变时也不能复用旧数据。
2. 后发请求的结果不会被先发请求覆盖。
3. 空响应和 `children` 为空时清空旧树并保留历史值。
4. 请求异常触发 `load-error`；响应缺少 `children` 数组归入 `load-empty`，reason 为 `empty-children`。
5. 当前节点存在时使用最新文本、样式和 `paths` 回写。
6. 当前节点不存在时仍能回显历史文本、路径和样式。
7. `v-model` 不包含 `children`，`paths` 使用节点对象数组。
8. 显式允许父节点选择时，根节点、中间节点和叶子节点都可以选择；默认仅叶子节点可选。
9. `allowParentSelect=false` 时父节点只能展开，搜索后仍然可以展开；`disableLevels` 只禁止指定层级选择。
10. 文本模式、路径模式、分隔符和显示层级符合配置。
11. 多选标签、路径标签、逐项删除和 `+N` 正常工作。
12. Storybook 覆盖基础选择、加载状态、历史值、多选、路径、搜索、外观和插槽场景。

## 8. 当前状态

需求已确认，`jd-relation-select-java` 已完成首版实现、导出和 Storybook 场景验证，最新源码基线为 `651c49b`。组件默认仅允许选择叶子节点，支持按层级禁选，并在选择入口再次校验非法值。真实业务接入、浏览器交互验收和错误提示文案仍由后续使用方确认。
