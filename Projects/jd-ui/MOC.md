# jd-ui 项目知识地图

jd-ui 是九鼎昊天前端 UI 库、工具库及相关应用的多包项目。本项目当前新增通用关系树选择组件的需求设计，组件计划服务于多个业务系统。

## 当前状态

通用关系树选择组件的业务需求已确认，jd-relation-select-java 已按 Arco 树选择器加自定义 trigger 插槽完成首版实现；原有 jd-relation-select 保持不变。当前实现保留历史值回显、默认仅末级可选、指定层级禁选、指定层级展示、节点视觉样式回显和实时加载结果事件等约束。
